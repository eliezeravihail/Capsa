## Current shape

Capsa is a passive, dependency-free file format for a project's management
capsule. `core/PRINCIPLES.md` (v0.4.0) defines the shared grammar every
format inherits: addresses (internal, relative, and external `@slug/path`),
typed `links`, tombstones, the verification block, and **placement** — a
record applies to the node holding it and everything beneath it, so what
governs any part of a system is derived by walking to the root rather than
declared with a scope field.

`project/SPEC.md` (v0.6.0) is the project format: requirements, plans,
decisions, discussions, issues, dependencies, releases, insights, the
component tree, interfaces, milestones, and release lines — with every
record type classified as normative (binds its subtree) or descriptive
(states a local fact). It names no record type for a dimension of
variation; a platform, a language, or a regulation is a requirement or a
component, not a type of its own.

`organization/SPEC.md` (v0.2.0) is a sibling format for a company's durable
memory — people, roles, teams, and the know-how that survives turnover —
with the same placement rule giving a second, independent walk: what binds
a *person* rather than a piece of *work*.

`tools/validator/validate.py` checks a capsule against these rules,
read-only and stdlib-only, on both the PyYAML and the dependency-free
parser path.
