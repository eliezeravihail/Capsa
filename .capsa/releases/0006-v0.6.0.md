## Highlights

The `platforms/` record type is removed. A platform constraint is a
requirement of the code, and a platform with code of its own is a component,
so the type named nothing the format could not already say — and privileging
one dimension of variation would have been an argument for a type per
language, per accessibility target, per regulation, without end.

`scoped_status[].scope` is now an ordinary internal address that must resolve
to any existing record, instead of a value from a closed `line:`/`platform:`
vocabulary. The format enumerates no dimensions; the check that a scope names
something real is unchanged.

The layout section (§2) no longer marks directories `OPTIONAL`. One word was
answering two unrelated questions — whether a *writer* must create the
directory, and whether a *reader* may skip what is in it — which left it
genuinely unclear whether an agent should open a section labelled optional.
The two are now separated, and what a reader must read is stated where it
belongs: everything normative on the walk from its node to the root.

## Notes

Breaking for a capsule that used platforms. Migration is a re-filing, not a
rewrite; the example capsule in this repository was migrated that way, and
the record type, its schema, and its template are deleted rather than
deprecated.
