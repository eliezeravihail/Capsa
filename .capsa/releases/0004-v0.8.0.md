## Highlights

Two of the three remaining open findings from the Netron capability test
are fixed; the fourth was already resolved as rejected.

**Core §Addresses gains a Web form** (`http://`/`https://`), for citing a
source outside any capsule entirely — a GitHub issue/PR, an RFC — as
structured `links` data instead of a sentence a checker can't follow.
Never resolved under any circumstance: a network request from a passive
validator would violate principle 1. Checked only for shape, the same
shallow guarantee `evidence_ref` already had.

**A dependency's filename is satisfiable for scoped npm packages.**
`/` escapes to `--` in the derived filename only — `name` keeps the real
identifier. `@playwright/test` → `npm-@playwright--test.md`.

## Notes

Both fixes are demonstrated live in `examples/netron/.capsa`, which now
validates with **zero** findings — no deliberate exceptions remain. All
four issues that exercise surfaced are now closed or rejected; none open.
