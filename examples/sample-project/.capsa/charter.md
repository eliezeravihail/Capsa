# Charter — Screen Recorder

## Vision
A minimal desktop screen recorder: record, pause, save as MP4. No accounts,
no cloud, no telemetry.

## Constraints
- Ships as a single binary; no GPL/AGPL dependencies (company policy).
- v1 targets Linux/X11 only.

## Ground rules
- Every bug closed leaves a regression test behind.
- Every dependency is an admitted decision, never a side effect.
